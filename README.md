A tiny Node program that writes one very funny office joke — a single line with a setup and a turn, punchline last — to `/output/entry.txt`, for make.fun's "The Funniest Office Joke, Judged Head to Head" bounty. A judge model reads entries two at a time and keeps the funnier one.

## Run it

```sh
node main.ts
```
